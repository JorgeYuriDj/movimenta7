# Segurança

## Relatar uma vulnerabilidade

Use o [canal privado de segurança do GitHub](https://github.com/JorgeYuriDj/movimenta7/security/advisories/new).
Não abra uma issue pública com segredo, URL privada da planilha, dado de participante ou instruções
de exploração. Informe o impacto, a forma de reproduzir e a versão afetada sem incluir dados reais.

Correção ou remoção de uma atividade do mapa não é uma vulnerabilidade: use o link **Peça a
correção ou remoção** no [site](https://jorgeyuridj.github.io/movimenta7/#secao-mapa). Esse pedido
vai somente para a planilha privada e nunca para o repositório.

## Versão coberta

A versão publicada a partir da branch `main` é a única mantida. Relatos sobre forks, cópias locais
ou planos históricos supersedidos não descrevem necessariamente o serviço em produção.
